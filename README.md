# FinStream

Real-Time Financial Transaction Monitoring & Anomaly Detection Platform.

## Objective

FinStream is a portfolio project designed to demonstrate
real-time data engineering and DevOps practices through a
simulated financial transaction monitoring platform.

## Planned capabilities

- Real-time transaction ingestion
- Apache Kafka event streaming
- Data validation and quality checks
- Transaction enrichment
- Rule-based anomaly detection
- PostgreSQL storage
- REST API
- Docker containerization
- CI/CD with GitHub Actions
- Kubernetes deployment
- Prometheus and Grafana monitoring
- Centralized logging
- AI-assisted transaction investigation

## Development constraint

The platform is designed to run locally without requiring
paid AWS infrastructure.
