# FinStream Project Goals

## Primary Objective

Build a production-style real-time financial transaction
monitoring platform while developing practical skills in
data engineering, DevOps, and AI-assisted systems.

## Data Engineering Goals

- Generate realistic transaction events continuously
- Understand Apache Kafka fundamentals
- Build real-time stream processing
- Implement data validation
- Handle malformed events using a dead-letter queue
- Store processed data in PostgreSQL
- Implement anomaly detection rules

## DevOps Goals

- Use Git effectively
- Containerize services with Docker
- Build CI/CD pipelines
- Deploy services to local Kubernetes
- Implement health checks and failure recovery
- Monitor the platform using Prometheus and Grafana
- Centralize application logs

## AI Goals

- Build an AI-assisted investigation component
- Provide contextual explanations for suspicious transactions
- Keep humans in the decision-making loop

## Cost Constraint

The core platform must be runnable locally without requiring
paid AWS infrastructure.
